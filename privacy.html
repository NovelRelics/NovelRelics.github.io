Privacy policy

Last updated: October 7, 2026.

This policy describes how Channel Insights Local, a personal Windows application operated by the owner of the Novel Relics channel, handles Google and YouTube data.

Data accessed

After the owner grants access, the application uses YouTube Analytics API and YouTube Data API to read the authorized channel's identity, video IDs and metadata, and requested analytics reports. Available reports may include views, watch time, engagement, traffic sources, devices, countries and audience retention. The application also receives OAuth access and refresh tokens needed to make authorized API requests.

Only yt-analytics.readonly and youtube.readonly permissions are requested. The application does not request upload, publication, video modification or deletion permissions.

How data is used

Data is used to create local channel performance reports, distinguish API-reported content types, and support the owner's content planning and video workflow. Missing data and cached data are labelled. The application does not sell Google user data or use it for advertising or credit decisions.

Storage and security

Reports, exported JSON and CSV files, video metadata and report manifests are stored on the owner's Windows computer. The saved OAuth connection, including access and refresh tokens, is encrypted using Windows DPAPI for the current Windows user. The OAuth client configuration is stored locally and is not part of this public website.

The application communicates with Google's authorization and API services over HTTPS. The public website does not collect the channel's OAuth credentials, tokens or analytics reports.

Sharing and AI-assisted analysis

The local reporting tool has no automatic public report-publishing feature. When the owner uses an AI assistant to analyze reports or plan content, the relevant report data or summaries may be made available to that assistant's service as part of the owner's authorized workflow. Credentials and tokens are not needed for that analysis and must not be shared. Any such transfer must be limited to the requested analysis and handled in accordance with Google's Limited Use requirements. The local application does not contain an AI model-training feature.

The website is hosted on GitHub Pages. GitHub may process website visitor information, including IP addresses, under its privacy statement. This website does not add analytics trackers, forms or an OAuth login flow.

Retention and deletion

Local reports are retained until the owner deletes them; a report's eligibility as a cache does not determine its storage lifetime. The owner can delete local reports and the encrypted connection file at any time. Data separately provided to an AI service is subject to that service's retention and deletion controls.

The owner can revoke the application's Google access through Google Account connections. Revoking access stops future authorized requests but does not automatically delete previously exported reports; those must be deleted locally.

Google user data commitment

Channel Insights Local's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.
